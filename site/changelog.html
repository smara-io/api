What's New in Smara

Changelog & Roadmap

v1.2.0 April 2026 Current
  • Team collaboration: shared project memories with private preferences that stay personal
  • AI Agents: autonomous memory access with role-based permissions and custom skills
  • Billing integration: Stripe subscriptions for Free, Developer, and Pro tiers
  • Webhook notifications: Stripe to Telegram alerts for new customers and subscription events
  • Blog: 5 SEO-optimized articles published covering AI memory, Ebbinghaus decay, and comparisons
  • Interactive playground at smara.io/playground
v1.1.0 March 2026
  • Ebbinghaus decay scoring: R = e^(-t/S) formula for memory relevance over time
  • Source tagging: track which tool stored each memory for provenance
  • REST API alongside MCP protocol for direct integration
  • Comparison page vs Mem0, Letta, and Zep with feature-by-feature breakdown
v1.0.0 February 2026
  • Initial launch: MCP server for Claude Code with zero-config auto-memory capture
  • PostgreSQL + pgvector backend for scalable vector storage
  • Semantic search with Voyage AI embeddings for high-accuracy recall
  • Auto-memory capture: decisions and context saved without manual tagging
  • Free tier: 10,000 memories to get started
