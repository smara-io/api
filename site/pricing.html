Frequently asked questions

Is Smara really free?
Yes. Smara is MIT licensed and open source. Self-host with unlimited memories at no cost. The hosted API gives you 10,000 memories free — no credit card needed.
What happens if I exceed 10,000 memories on the hosted API?
You'll get a warning at 90% usage. Existing memories remain fully searchable. You can self-host for unlimited capacity, or contact us about Enterprise for managed unlimited.
What do I need to self-host?
A server with Docker and PostgreSQL with pgvector. One docker compose up gets you running. Works on any cloud provider, VPS, or local machine. Full instructions in the GitHub repo.
Is my data private?
On the hosted API, each API key isolates your data. All data encrypted in transit (TLS 1.3) and at rest. We never use your memories for training. Self-hosting gives you complete data sovereignty.
Can I migrate from the hosted API to self-hosted?
Yes. Export your memories via the REST API and import them into your self-hosted instance. The API is identical, so your code doesn't change — just point to your own server.
