Frequently asked questions

Can I start free and upgrade later?
Yes. The free tier gives you 10,000 memories with full API access — no credit card required. Upgrade to Pro or Team anytime. Changes are prorated.
What happens if I hit my memory or rate limit?
You'll get a warning at 90% usage. Existing memories remain fully searchable. New writes will be queued. Upgrade to lift limits instantly, or self-host for unlimited capacity.
What's the difference between hosted and self-hosted?
Hosted: we manage the infrastructure, you get an API key and go. Self-hosted: you run Smara on your own server with Docker — unlimited everything, MIT license, full data sovereignty.
Is my data private?
On the hosted API, each API key isolates your data. All data encrypted in transit (TLS 1.3) and at rest. We never use your memories for training. Self-hosting gives you complete data sovereignty.
Can I switch between plans or migrate to self-hosted?
Yes to both. Upgrade or downgrade at any time. To self-host, export your memories via the REST API and import them — your code doesn't change, just point to your own server.
