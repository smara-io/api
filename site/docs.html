Smara API Reference

Persistent memory for AI tools. Store, search, and connect knowledge across sessions.

Base URL
https://api.smara.io
Auth
Bearer <api_key>
Format
JSON (application/json)
Quick Start — MCP Config
JSON — claude_desktop_config.json 
{
  "mcpServers": {
    "smara": {
      "command": "npx",
      "args": ["@smara/mcp-server"],
      "env": {
        "SMARA_API_KEY": "smara_your_api_key_here"
      }
    }
  }
}
Authentication

All API endpoints (except signup, feedback, and webhooks) require a Bearer token. Pass your API key in the Authorization header.

HTTP Header 
Authorization: Bearer smara_your_api_key_here
